# SaveMoney

Учебное приложение для личного бюджета по методу конвертов.

- [Сервер и REST API](app/backend/README.md) — Python 3.13, MongoDB, OpenAPI.
- `app/frontend` — мобильный интерфейс на React, TypeScript и Vite.
- [Архитектура](PROJECT.md) и [третий чек-поинт](CHECKPOINT3.md).

## Локальный запуск с сервером

Запустите [Python API и MongoDB](app/backend/README.md#запуск-api-с-mongodb).
Для нового бюджета используйте `python -m savemoney.server --init` из `app/backend`.

В другом терминале, из корня репозитория:

```sh
cd app/frontend
bun install --frozen-lockfile
bun run dev
```

Для команд фронтенда нужны Bun и Node.js 22+.

Откройте адрес Vite. Запросы `/api/v1` идут через локальный прокси на
`http://127.0.0.1:8000`. Для другого порта укажите `SAVEMONEY_API_TARGET` при
запуске Vite. Если нужен доход, создайте категорию типа «Доход» в настройках.

Фронтенд получает снимок бюджета и расчёт баланса через существующие операции REST.
Изменения идут через маршруты операций, категорий и других ресурсов. В серверном
режиме справочники архивируются или отключаются с сохранением истории.
Экспорт и импорт используют снимок сервера, совместимый с Python CLI.
Создание операции требует открытого периода. Новый текущий месяц можно открыть
на главном экране.

## Публичное PWA-демо

```sh
cd app/frontend
bun install --frozen-lockfile
bun run build:demo
bun run preview:demo
```

Для QR разместите содержимое `app/frontend/dist-demo/` в корне
`https://save-money.tru3ty.ru/` на статическом хостинге с действующим HTTPS.
После первого открытия подождите окончания загрузки. В демо можно добавлять
доходы и расходы, перезагружать страницу и повторять действия офлайн.
Данные из примера и изменения посетителя хранятся в его браузере. Настройки
позволяют восстановить исходное демо.

В Chrome на Android установка доступна в меню браузера, в Safari на iPhone —
через «Поделиться» → «На экран Домой». Ссылку из QR можно открыть и без установки.
Для `index.html` и `sw.js` используйте `Cache-Control: no-cache`, чтобы браузер
проверял обновления. Публичная сборка работает без Python API и MongoDB.
